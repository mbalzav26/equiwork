# 5.7.3 Integración de software en hardware

EquiWork forma un sistema integral al ejecutar el software de aplicación sobre hardware con roles definidos, según el diagrama de despliegue. En **cliente**, estaciones de trabajo (PC del administrador o del supervisor/colaborador) ejecutan un navegador web estándar sobre sistema operativo de escritorio; no se instala aplicación nativa: el hardware solo requiere conectividad de red, resolución adecuada para las vistas EJS y recursos para renderizar HTML, CSS y JavaScript (Chart.js en reportes). Las peticiones salen por HTTP/HTTPS hacia el servidor.

En **servidor**, el runtime **Node.js** (≥ 18) corre sobre un procesador de propósito general con memoria RAM suficiente para el proceso Express, la compilación de vistas y el pool de conexiones Sequelize. Los artefactos `express-http` y `assets-web` atienden tráfico y archivos estáticos; `equiwork-app`, `vistas-ejs` y `sequelize-orm` residen en el mismo nodo lógico de aplicación en despliegues pequeños o en máquinas separadas en producción. La **capa de datos** usa disco persistente: archivo SQLite en desarrollo o servidor **MySQL** en producción (CPU, RAM y almacenamiento del motor de base de datos). La integración física se completa con red TCP/IP entre cliente y puerto configurado (`PORT`, por defecto 3000) y entre aplicación y base (`DB_HOST`/`DB_PORT` o ruta del archivo `.sqlite`). Variables de entorno (`.env`) adaptan el software al hardware disponible sin cambiar el código, de modo que el mismo binario Node se despliega en entorno local o en un VPS con MySQL remoto.
