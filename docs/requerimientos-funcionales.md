# 5.2.3 Requerimientos funcionales

| Referencia | Requerimiento |
|------------|---------------|
| RF01 | Yo como Administrador, Supervisor o Colaborador deseo iniciar sesión con correo y contraseña para acceder a EquiWork de forma autenticada y segura. |
| RF02 | Yo como Administrador, Supervisor o Colaborador deseo cerrar sesión para finalizar mi acceso al sistema y proteger mi cuenta en equipos compartidos. |
| RF03 | Yo como Administrador o Supervisor deseo consultar el balance de carga laboral por quincena (totales, distribución y estado del equipo) para identificar sobrecarga o subutilización oportunamente. |
| RF04 | Yo como Administrador o Supervisor deseo listar y buscar colaboradores registrados para disponer de la información base de personal activo e inactivo. |
| RF05 | Yo como Administrador o Supervisor deseo registrar colaboradores (datos de identificación, contacto y estado) para mantener actualizado el maestro de personal. |
| RF06 | Yo como Administrador o Supervisor deseo actualizar la información de un colaborador para corregir o completar datos cuando cambien en la organización. |
| RF07 | Yo como Administrador deseo desactivar colaboradores que ya no hacen parte del equipo para evitar nuevos registros sobre personal inactivo sin borrar su historial. |
| RF08 | Yo como Administrador o Supervisor deseo crear la cuenta de acceso a la encuesta para un colaborador activo para que pueda autoreportar su carga laboral quincenal. |
| RF09 | Yo como Administrador o Supervisor deseo registrar eventos quincenales de carga (fecha, horas, tipo y descripción) asociados a un colaborador y quincena para documentar la actividad del periodo. |
| RF10 | Yo como Administrador o Supervisor deseo consultar el historial de eventos de un registro quincenal para revisar intervenciones previas antes de registrar o ajustar información. |
| RF11 | Yo como Administrador o Supervisor deseo eliminar un evento quincenal registrado para corregir errores de captura manteniendo la integridad del periodo. |
| RF12 | Yo como Administrador o Supervisor deseo generar y exportar reportes quincenales (visualización y CSV) para analizar la carga del equipo y respaldar decisiones de gestión. |
| RF13 | Yo como Colaborador deseo registrar mis propios eventos de carga en la encuesta quincenal para reportar de forma directa las actividades realizadas en el periodo. |
| RF14 | Yo como Colaborador deseo consultar el historial y el resumen de mis eventos en la encuesta para verificar horas acumuladas y coherencia de mi autoreporte. |
| RF15 | Yo como Colaborador deseo eliminar un evento propio registrado en la encuesta para corregir un error sin depender del supervisor en ajustes menores. |
